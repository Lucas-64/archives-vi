# Archives VI Roadmap

## MVP

Goal: create a polished first version of the Home experience and the reusable
foundation needed to build the rest of the product.

- Stabilize Next.js (App Router) + React + TypeScript architecture.
- Confirm `src/components` as the official component directory.
- Build the first design system primitives.
- Complete Home MVP sections:
  - Header
  - Hero
  - Featured cases
  - Trending cases
  - Community/sidebar module
  - Footer
- Define core case data model.
- Add mock case data.
- Improve responsive behavior and accessibility.

## Community

Goal: support community-oriented discovery and discussion flows.

- Forum topic preview modules.
- Community investigation lists.
- Theory submission model.
- Contribution metadata.
- Moderation-ready content statuses.
- Comment and discussion UX specifications.

## Authentication

Goal: prepare user identity and contribution ownership.

- Account creation flow.
- Login/logout flow.
- User profile model.
- Contributor badges.
- Saved cases and followed theories.
- Admin/moderator roles.

## Interactive Map

Goal: allow users to explore mysteries by location.

- Leonida map discovery model.
- Case markers and status indicators.
- Region filters.
- Location detail drawer.
- Evidence linked to coordinates.
- Mobile-friendly map interactions.

## Launch Version

Goal: deliver a stable public portfolio-ready release.

- Final Home MVP.
- Cases archive.
- Case detail view.
- Search and filters.
- Accessibility review.
- Performance review.
- Content seed data.
- Documentation updated for public presentation.
- Deployment pipeline.

## Future Versions

Goal: evolve Archives VI into a broader community platform.

- Next.js migration after Home MVP completion.
- Server-rendered case pages.
- Supabase or equivalent backend integration.
- Rich submissions with review queue.
- Notifications for followed cases.
- Advanced analytics for trending investigations.
- Internationalization support.
