# OKRs and KPIs

## Product OKRs

Objective: Create a compelling MVP foundation for Archives VI.

Key Results:

- Complete Home MVP sections.
- Create typed case data model.
- Publish at least 6 mock cases for development.
- Document roadmap and release plan.

KPIs:

- Home MVP completion percentage.
- Number of reusable components used in Home.
- Number of documented product decisions.

## Community OKRs

Objective: Prepare Archives VI for future community participation.

Key Results:

- Document submission workflow.
- Define moderation statuses.
- Define community topic model.
- Identify risks for user-generated content.

KPIs:

- Submission workflow readiness.
- Moderation requirements coverage.
- Number of community features refined in backlog.

## Engineering OKRs

Objective: Build a scalable front-end foundation.

Key Results:

- Keep Styled Components as the official styling approach.
- Reduce duplicated UI implementation.
- Create official UI primitives before new pages.
- Maintain successful production builds after code changes.

KPIs:

- Build success rate.
- Number of official design system primitives.
- Number of components using theme tokens.
- Technical debt items closed per sprint.

## Portfolio Impact OKRs

Objective: Present Archives VI as a professional product and Scrum portfolio
case.

Key Results:

- Maintain complete product documentation.
- Provide ClickUp-ready backlog and CSV import.
- Document sprint history and release plan.
- Show clear architecture and decision-making.

KPIs:

- Documentation completeness.
- Number of Scrum artifacts created.
- Recruiter review readiness score.
- Case study clarity and completeness.
