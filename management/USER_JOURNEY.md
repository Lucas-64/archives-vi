# User Journey

## 1. Discover the Site

User intent:

- Understand what Archives VI is and whether it is worth exploring.

Experience:

- Visitor lands on the Home page.
- Header communicates the brand.
- Hero introduces the investigation/mystery concept.

Opportunities:

- Improve Hero copy and CTA clarity.
- Add completed Home MVP modules.

## 2. Explore Cases

User intent:

- Browse active mysteries and find something interesting.

Experience:

- Visitor scans featured and trending cases.
- StatusBadge communicates investigation state.
- CaseCard will summarize title, status and metadata.

Current state:

- Hero contains a featured case concept.
- CaseCard and typed case data are planned.

## 3. Read Evidence

User intent:

- Understand why a case exists and what evidence supports it.

Experience:

- Visitor opens a case detail page in a future release.
- Evidence is grouped by type and source.

Current state:

- Evidence model is not implemented.
- Case detail pages are planned for Cases MVP.

## 4. Compare Theories

User intent:

- Evaluate multiple interpretations of the same mystery.

Experience:

- Visitor compares theory summaries, confidence and supporting evidence.

Current state:

- Theory model is planned.
- Community theory workflows are future backlog.

## 5. Submit Discoveries

User intent:

- Contribute a new finding or theory.

Experience:

- Authenticated user submits discovery details, evidence and location.
- Submission enters moderation or review.

Current state:

- Authentication and submissions are planned.
- Moderation workflow must be specified before implementation.

## 6. Join Discussions

User intent:

- Participate in community investigation.

Experience:

- User joins discussions around cases, theories or map locations.

Current state:

- Forum/community features are planned for later milestones.

## Journey Metrics

- Home bounce rate.
- Case card click-through rate.
- Case detail read depth.
- Theory engagement.
- Submission completion rate.
- Discussion participation rate.
